# ChatRealTime

A real-time chat web application built with **Node.js**, **Express**, and **Socket.IO**.

## Features

- 💬 Real-time messaging with Socket.IO
- 👥 Live online user list in sidebar
- ✍️ Typing indicators
- 🎨 Clean, responsive UI with mobile support
- 🕐 Message timestamps

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or higher

### Installation

```bash
# Clone the repository
git clone https://github.com/ManhThang191/ChatRealTime.git
cd ChatRealTime

# Install dependencies
npm install
```

### Running the App

```bash
npm start
```

Then open your browser and navigate to [http://localhost:3000](http://localhost:3000).

To test real-time features, open the URL in multiple browser tabs or windows.

## Tech Stack

| Layer    | Technology |
|----------|-----------|
| Backend  | Node.js + Express |
| Real-time | Socket.IO |
| Frontend | HTML, CSS, Vanilla JS |
